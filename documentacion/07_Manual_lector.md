# Manual del lector

DTS · Desarrollo & Tecnología Santander. Entorno QA.

## Módulos y alcance

El lector consulta las empresas y proyectos asignados, solicitudes permitidas, instalaciones/versiones publicadas, catálogo, cobertura pública, servicios públicos, agenda publicada, conocimientos, notificaciones y cuenta. Su rol base no permite crear solicitudes, escribir comentarios, cambiar estados ni administrar datos, personas o permisos. Si necesita realizar gestión, debe solicitar al propietario una revisión de su rol.

## 1. Entrar y seleccionar proyecto

1. Aceptar la invitación con el correo correcto y verificado o entrar con la cuenta autorizada.
2. Abrir el menú lateral; en pantalla pequeña usar Abrir menú.
3. Seleccionar empresa y proyecto en los controles superiores.
4. Revisar el Resumen del contexto seleccionado.

## 2. Consultar documentación y operación

1. Abrir Proyectos para consultar la ficha.
2. Usar Instalaciones y versiones para revisar la versión publicada.
3. Consultar Catálogo funcional y Base de conocimientos para conocer funciones e instrucciones.
4. Consultar Contratos y cobertura y Servicios y renovaciones para las fichas públicas de vigencia.
5. Revisar Implementación y agenda para reuniones, capacitaciones y compromisos publicados.
6. Usar búsqueda, filtros y paginación. Si no aparecen registros, verificar el proyecto y consultar a DTS si falta publicación o acceso.

## 3. Seguir solicitudes

1. Abrir Solicitudes y PQRS.
2. Filtrar por estado o buscar el asunto/número.
3. Abrir el detalle y leer descripción, eventos y conversación pública autorizada.
4. Identificar estado, cobertura y última actualización.
5. Abrir la campana Trazabilidad de notificaciones para consultar eventos visibles y sus avisos personales.

Si hace falta corregir algo, avisar al responsable por el canal acordado y citar el número DTS. El lector no agrega comentarios ni cierra/reabre solicitudes. Tampoco consulta notas internas o técnicas.

## 4. Configurar y leer avisos

1. Abrir Mi cuenta y revisar los registros Web y Celular.
2. Pulsar Activar notificaciones en este dispositivo y aceptar el permiso.
3. Abrir Notificaciones y desplegar cada novedad para revisar envío a ambos canales.
4. Elegir Ver detalle para abrir la información autorizada o Leído para registrar que revisó el aviso.

Se conserva el último navegador y la última aplicación celular por separado. El siguiente acceso en otro equipo del mismo tipo sustituye ese destino. La web abierta desde un teléfono cuenta como web. Si push está bloqueado, la bandeja sigue funcionando. Aceptado por Firebase no demuestra recepción; apertura y lectura requieren confirmación. iOS necesita además configuración Apple/APNs de DTS.

## 5. Errores y cierre de sesión

Usar Volver a intentar ante un fallo temporal de conexión. Si un proyecto no aparece o una operación informa falta de permisos, pedir revisión al propietario. No usar la cuenta de otra persona para acceder. Al terminar, cerrar sesión desde el menú o Mi cuenta, especialmente en equipos compartidos. El cierre desactiva ese destino para nuevos avisos.
